# Contributing to agy-switch

Thank you for your interest in contributing to **agy-switch**!

## Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/jack101a/agy-switch.git
   cd agy-switch
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Build the project:**
   ```bash
   npm run build
   ```

4. **Run the TUI:**
   ```bash
   npm run tui
   ```

5. **Run the Web Dashboard:**
   ```bash
   npm run dashboard
   ```

## Pull Request Guidelines

- Ensure TypeScript compiles with zero errors (`npm run build`).
- Keep code formatted cleanly and maintain modular architecture.
- Test across both desktop and mobile/narrow terminal viewports.
